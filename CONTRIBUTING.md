# Contributing

**This is a personal fork, kept for its owner's own use.** It does not solicit
contributions, and it has no contribution process — the upstream's issue and
pull request templates were removed rather than rewritten, because there is no
workflow here for them to serve.

**Contributing to the original project?** That happens at
[obra/superpowers](https://github.com/obra/superpowers), under its own
guidelines and its own templates. Nothing sent here reaches it: this fork is
not connected to the upstream's maintainers, its review process, or its
release schedule, and a change landed here never propagates upstream.

**Something wrong with this fork specifically?** Open an issue on
[this repository](https://github.com/rodrigopaitach/superpowersplus/issues).
That includes anything covered by [`CODE_OF_CONDUCT.md`](CODE_OF_CONDUCT.md),
which is inherited from upstream but enforced only here.

What this fork changes relative to upstream is recorded in
[`PLUS-CHANGELOG.md`](PLUS-CHANGELOG.md). Documentation in
[Portuguese](docs/README.pt-BR.md) and [English](docs/README.en.md).
